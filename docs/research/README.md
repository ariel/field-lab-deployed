# A field system you can remember

**Shoot. Copy. Check. Keep.**

Use [this single field guide](ONE-PAGER.md), or take [the one-page PDF](ONE-PAGER.pdf). It contains the preparation, field routine and return-home rule in one place.

The physical system is two card pockets, READY and USED, plus two independent backup drives. Recorded cards stay in USED for the whole shoot, even after a successful copy. OffShoot verifies each card onto Drive 1, then the saved CCC task verifies its copy onto Drive 2. Organize in Finder on Drive 1 when useful, then run the same CCC task; Drive 2 follows. OffShoot keeps the transfer reports. A voice note is optional when something matters that you may forget.

There are no required CSVs, metadata IDs, look registers, clip logs or approval forms. Premiere work waits until you are home. This assumes enough card capacity for the day; plan that before departure.

[A short worked shoot and desk setup](reference/AT-HOME.md) is available if you want to rehearse the routine once. You do not need it open in the field.
